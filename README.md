# TNL Mail

Open-source, self-hosted business webmail PWA built with PHP and SQLite.

**Status: planning / early development. Not production ready.**

## Modules
- Mail: IMAP/SMTP business email
- Chat: planned end-to-end encrypted private messaging
- Files: personal file manager
- Shared: team file spaces and permissions
- PWA: installable web interface and optional Web Push
- MCP: optional scoped AI integration

Google Drive and video meetings are postponed.

## Principles
Portable installation on compatible shared hosting; SQLite instead of a database server; security-first design; no secrets or customer data in Git.

## Roadmap
1. PHP and SQLite installer, authentication, PWA foundation.
2. IMAP/SMTP email client.
3. Private and shared file management.
4. Chat with reviewed E2EE protocol and secure device key management.
5. Push notifications and optional MCP server.
